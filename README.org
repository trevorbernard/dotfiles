* Dotfiles

My various configuration files managed with GNU Stow.

** Usage

Most packages are installed by stowing into ~$HOME~ (their internal
structure already includes the leading dot, e.g. ~tmux/.tmux.conf~):

#+begin_src bash
  stow -t $HOME <directory>
#+end_src

For example, to install tmux configuration:

#+begin_src bash
  stow -t $HOME tmux
#+end_src

Packages whose files live outside ~$HOME~ (under ~~/.config~, ~~/bin~,
~~/.claude~) use a different stow target — see the per-section notes
below.

To install everything at once:

#+begin_src bash
  for pkg in git lein tmux zsh; do stow -t $HOME $pkg; done
  stow -t $HOME/bin bin
  stow -t $HOME/.claude claude
  stow -t $HOME/.config ghostty ghostty-linux podman starship  # or ghostty-macos
  stow -t $HOME/.config/hunk hunk
  stow -t $HOME/.config/tuicr tuicr
#+end_src

** Tests

Scripts under ~tests/~ are plain bash and run standalone. They build
throwaway git repositories under a temp directory, so they never touch
this one:

#+begin_src bash
  ./tests/test-better-branch
  ./tests/test-eat-trailing-whitespace
#+end_src

Or all of them, stopping at the first failure:

#+begin_src bash
  for t in tests/test-*; do "$t" || break; done
#+end_src

~tests/~ is deliberately not a stow package — ~bin/~ is stowed onto
~PATH~, so test scripts must live outside it.

** Configurations

*** bin

Personal shell scripts (~better-branch~, ~eat-trailing-whitespace~,
~osc52-copy~). Stowed directly to ~$HOME/bin~:

#+begin_src bash
  stow -t $HOME/bin bin
#+end_src

Both the macOS and linux branches of the zsh config add ~$HOME/bin~ to
~PATH~.

*** Claude

Claude Code settings (~CLAUDE.md~ and ~settings.json~). Stowed to
~$HOME/.claude~:

#+begin_src bash
  stow -t $HOME/.claude claude
#+end_src

Only ~settings.json~ is tracked. Claude Code writes machine-local state
into ~settings.local.json~ — permission grants and the absolute paths
they refer to — so that file is gitignored and deliberately left
unstowed, keeping it out of this repo.

*** Ghostty

Configuration for the Ghostty terminal emulator. Shared settings live in
the ~ghostty~ package; the platform-specific overrides live in
~ghostty-linux~ and ~ghostty-macos~, which are separate packages so that
only the one matching this machine is ever linked:

#+begin_src bash
  stow -t $HOME/.config ghostty ghostty-linux   # or ghostty-macos
#+end_src

Each package holds a ~ghostty/~ subdirectory, the same shape as ~podman~,
so the files land in ~$HOME/.config/ghostty/~. Stow folds that directory
into a symlink if only one package claims it and unfolds it again when
the second arrives, so stowing the two in either order or separately all
work.

They are separate packages rather than three files in one on purpose.
Stow links every file in a package, so holding ~config_macos~ next to
~config_linux~ put both on every machine, and since ~config~ pulls them in
last, the macOS padding quietly won on Linux.

*** Git

Git configuration and aliases.

**** Machine-specific email

The git config uses an include directive to load machine-specific
settings from ~~/.gitconfig.local~. After stowing, set up your email:

#+begin_src bash
  cp ~/.gitconfig.local.example ~/.gitconfig.local
  # Edit ~/.gitconfig.local to set your email
#+end_src

*** Hunk

Configuration for the Hunk terminal diff viewer (~config.toml~). Stowed
to ~$HOME/.config/hunk~ rather than ~$HOME/.config~ so the directory
itself stays real — Hunk writes runtime state (~state.json~) alongside
the config, and that shouldn't end up in this repo:

#+begin_src bash
  stow -t $HOME/.config/hunk hunk
#+end_src

The target directory must exist first (run ~hunk~ once or ~mkdir -p
~/.config/hunk~).

*** Lein

Leiningen configuration for Clojure development with CIDER integration
and useful aliases.

*** Podman

Container registry policy. Stowed to ~$HOME/.config~ (creates
~$HOME/.config/containers/policy.json~):

#+begin_src bash
  stow -t $HOME/.config podman
#+end_src

*** Starship

Starship prompt configuration. Stowed to ~$HOME/.config~ (creates
~$HOME/.config/starship.toml~):

#+begin_src bash
  stow -t $HOME/.config starship
#+end_src

*** TMUX

**** Mac specific configuration

The following packages should be installed to get optimal TMUX experience
on MacOS.

#+begin_src bash
  brew install reattach-to-user-namespace
  brew install pam-reattach
#+end_src

*** Tuicr

Configuration for the tuicr code review TUI (~config.toml~). Stowed to
~$HOME/.config/tuicr~ so the directory itself stays real:

#+begin_src bash
  mkdir -p ~/.config/tuicr
  stow -t $HOME/.config/tuicr tuicr
#+end_src

*** ZSH

Configuration for ZSH shell with Starship prompt.
